# Переводчик экрана: китайский / английский → русский

Плавающая кнопка «译» поверх всех приложений. Нажали — экран распознаётся и перевод
появляется прямо поверх оригинального текста. Коснулись экрана — перевод исчез.

- Бесплатно, без подписок, рекламы и ключей API.
- Распознавание (OCR) и перевод — Google ML Kit прямо на телефоне. После однократного
  скачивания моделей (~60 МБ) работает без интернета.
- Язык (китайский или английский) определяется автоматически для каждого абзаца.
- Android 8.0 и новее.

## Скачать APK
- **С сайта:** https://minisul.app — кнопка «Скачать APK».
- **Здесь, в разделе Releases:** `ScreenTranslator.apk` — для почти всех телефонов (arm64), `ScreenTranslator-armv7.apk` — для старых телефонов.

## Собрать самому (Android Studio)
1. File → Open → папка проекта, дождитесь синхронизации Gradle.
2. Build → Build App Bundle(s) / APK(s) → Build APK(s).
3. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Первый запуск
1. «Разрешить показ поверх других приложений» → включите переключатель.
2. «Скачать языковые модели» (нужен интернет один раз).
3. «Запустить переводчик» → в системном окне разрешите запись **всего экрана**.
4. Откройте нужное приложение и нажмите синюю кнопку «译».

## Важно знать
- Пока переводчик включён, Android показывает значок записи экрана — так положено системой.
  Снимки никуда не отправляются, всё обрабатывается на телефоне.
- Банковские приложения и некоторые видеосервисы запрещают снимки экрана —
  там перевод не сработает (будет чёрный экран).
- На некоторых версиях Android захват прекращается после блокировки телефона —
  просто запустите переводчик снова.
- Перевод машинный и офлайн: смысл передаёт хорошо, но бывает корявым.
